# alife

Экосистема, в которой особи с нейросетевыми «мозгами» эволюционируют без
заданной функции приспособленности. Отбор идёт только через выживание:
особь живёт, ест, размножается и умирает по внутренней энергии, мир
никогда не сбрасывается.

Основание — обзор исследований 2023–2026 годов (Bejjani 2025, Mandl 2026,
Flow-Lenia 2025, Hamon 2023). Принципы оттуда закреплены в коде и в тестах,
а не только в документе.

## Что уже работает

Этапы 1 и 2: устойчивая экосистема с травоядением, без видов и без заданных
ролей, и окно наблюдения с инспектором особи.

```
cargo build --release
cargo test --release
./target/release/alife run --config configs/default.toml --steps 20000 --out runs/s1.csv
./target/release/alife-viewer --config configs/default.toml
```

Прогон на 20 000 шагов на сиде 1: популяция держится около 1500 особей,
106 поколений, вымирания нет, упора в потолок ёмкости нет. На сидах 2–4
картина та же (1264–1580 особей через 10 000 шагов), доля биомассы внутри
особей 19–23%. Скорость — около 320–450 шагов в секунду при полутора тысячах
особей на 16 потоках.

Хищничество пока почти не возникает: убийств на атаку порядка 0,005.
Это ожидаемо — специализированная охота относится к следующему этапу.

## Два обязательных свойства

Оба закреплены тестами и проверяются на каждом прогоне.

**Сохранение массы.** Биомасса не возникает и не исчезает. Она лежит в трёх
пулах клетки — растения, падаль, питательные вещества — и в энергии особей.
Любое действие только перекладывает массу между пулами: метаболизм и роды
отдают её в питательные вещества клетки, атака и смерть — в падаль, еда
забирает из клетки в энергию. CLI печатает накопленный уход массы в конце
прогона; на 20 000 шагов он порядка 1e-6 и объясняется только точностью f32.

**Детерминизм.** Один сид даёт побитово один и тот же прогон. Для этого:
решения считаются параллельно, но по неизменяемому миру, а применяются
строго по возрастанию номера слота; генератор случайных чисел свой
(xoshiro256++), а не из внешней библиотеки; системный `tanh` заменён
аппроксимацией, потому что он может отличаться между платформами.
Тест сравнивает отпечатки полного состояния двух прогонов.

## Устройство мира

Тор `width` x `height`, в клетке живёт не больше одной особи.

Каждый шаг состоит из четырёх фаз:

1. **Решения** — параллельно по всем живым особям. Сенсоры: окно 7x7 по
   четырём каналам (растения, падаль, питательные вещества, энергия соседа)
   плюс восемь скаляров — своя энергия, возраст, ела ли, били ли, плотность
   вокруг, растения и падаль под собой, смещение. Всего 204 входа.
2. **Действия** — последовательно, по возрастанию слота. Атака и движение
   исключают друг друга, иначе выгодна тактика «ударил и убежал». Направление
   одно: куда особь смотрит, туда и идёт, туда и бьёт.
3. **Метаболизм и смерть** — расход энергии растёт с возрастом, поэтому
   поколения сменяются даже в сытом мире.
4. **Среда** — разложение падали, логистический рост растений из
   питательных веществ, диффузия питательных веществ.

Хищничество не задаётся видом: атаковать может любая особь, убитая
оставляет падаль, которую может съесть кто угодно. Специализация должна
возникнуть сама.

Размножение — копия сети родителя плюс гауссов шум, без скрещивания.
Родитель отдаёт потомку долю своей энергии, ещё часть теряется в клетку.

## Просмотрщик

```
./target/release/alife-viewer --config configs/default.toml --seed 7
```

Окно собрано не ради красоты: по одним числам популяции не видно ни тихого
бага в сенсорах, ни того, что особи делают на самом деле.

**Карта.** Зелёное — растения, красное — падаль, синеватая подложка —
питательные вещества. Особи раскрашиваются по линии (родственники видны
пятном одного цвета), по энергии, возрасту или поколению. Колесо мыши —
масштаб вокруг курсора, перетаскивание — панорама.

**Инспектор.** Щелчок по особи раскрывает её целиком: номер, линию,
родителя, поколение, возраст, энергию; решение на этот шаг; все восемь
выходов сети со знаком и отметкой выбранного; окно обзора 7x7 по каждому
из четырёх каналов отдельной тепловой картой; все восемь скалярных входов
числами. Выбранную особь можно вести камерой.

Инспектор считает ровно то же, что параллельная фаза шага, — те же сенсоры
и та же сеть, только для одного слота и без побочных эффектов. Тест
`inspection_predicts_the_next_move` проверяет, что предсказанное
перемещение совпадает с фактическим.

**Графики.** Численность, доля биомассы в особях, средний возраст,
растительная масса, еда на особь за шаг, убийств на атаку. Рисуются
своим кодом: `egui_plot` тянет несовместимую с `eframe` версию egui,
а нужен был только ряд значений во времени.

Пробел — пуск и пауза, точка — один шаг. Сверху видно уход массы за прогон
и фактическую скорость в шагах в секунду.

## Структура

```
crates/alife-core     ядро, ничего не знает об отрисовке
  rng.rs              свой генератор случайных чисел
  config.rs           все параметры баланса в одном месте
  world.rs            сетка и три пула массы
  agents.rs           особи как структура из массивов
  brain.rs            сеть, плоская раскладка весов
  sense.rs            сенсоры и нормировка входов
  sim.rs              шаг симуляции
  metrics.rs          счётчики и запись CSV
crates/alife-cli      пакетный прогон без отрисовки
crates/alife-viewer   окно наблюдения на egui
  worldview.rs        карта мира и камера
  inspector.rs        сенсоры и выходы сети одной особи
  charts.rs           графики метрик
configs/default.toml  базовая конфигурация с пояснениями
```

Данные везде лежат плоскими массивами: геномы всей популяции — один
непрерывный буфер. Это нужно и для скорости на CPU, и чтобы позже отдать
те же буферы в compute-шейдер.

## Память

Геномы — главная статья расхода: `capacity * весов * 4 байта`. При
`capacity = 12288` и сети `204 -> 32 -> 32 -> 8` это 7880 весов на особь
и 369 МБ. Сеть `64 -> 64` из обзора даёт примерно 18 тысяч весов;
при сотне тысяч особей это уже гигабайты, и ёмкость придётся поднимать
вместе с переходом на GPU и половинную точность.

CLI печатает фактический расход при старте.

## Метрики

CSV с колонками: численность, масса по пулам, доля биомассы внутри особей,
средние энергия и возраст, максимальное поколение, рождения, смерти от
голода и от убийств, атаки, убийств на атаку, действия на особь.
